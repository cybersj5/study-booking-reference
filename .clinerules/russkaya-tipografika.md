# Русская типографика проекта

Правило касается текста, который читает человек: документации, сообщений об ошибках,
подписей в интерфейсе, комментариев. Кода, команд, путей и англоязычных строк
не касается.

## Что проверить

1. Длинных тире нет. Вместо них двоеточие, точка или запятая.
2. Кавычки «ёлочки» в русском тексте. Прямые кавычки только внутри кода.
3. Числа от тысячи с неразрывным пробелом: 2 000. Десятичная запятая: 1,5 часа.

## Как проверить

Ищу по изменённым файлам и показываю список найденных мест с номерами строк.
Ничего не исправляю, пока не покажу список.

```bash
grep -rnP "(*UTF)\x{2014}" --include="*.md" --include="*.ts" --include="*.tsx" .
```

То же в PowerShell:

```powershell
Select-String -Path *.md, *.ts -Pattern ([char]0x2014)
```

Пустой вывод означает, что правило соблюдено.

## Примеры

Длинное тире в таблице записано как `&mdash;`, иначе файл правила нарушал бы
собственное правило и первая же команда поиска нашла бы его самого.

| Было | Стало |
| --- | --- |
| `Ошибка &mdash; слот занят!` | `Этот слот уже забронирован.` |
| `Бронь отменена &mdash; время свободно` | `Бронь отменена, время освободилось.` |
| `Активность "Код-ревью" удалена` | `Активность «Код-ревью» удалена` |
| `Вместимость: 2000 мест` | `Вместимость: 2 000 мест` |
| `Встреча длится 1.5 часа` | `Встреча длится 1,5 часа` |
